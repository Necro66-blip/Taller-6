Analizador de Comentarios en Python

Curso: Lógica de Programación I

1. Descripción del proyecto

El Analizador de Comentarios es un programa desarrollado en Python que permite registrar y analizar comentarios de estudiantes. Sus funcionalidades incluyen buscar palabras, contar palabras y apariciones, y generar resúmenes con información de cada comentario.

2. Requisitos generales

Tener Python 3 instalado.

Contar con el archivo main.py.

Disponer de una terminal o editor de código.

No requiere instalar librerías externas.

3. Cómo ejecutarlo

Guarda el código fuente en un archivo llamado main.py.

Abre una terminal en la carpeta del proyecto.

Ejecuta el siguiente comando:

python main.py

Si el comando anterior no funciona, prueba python3 main.py o py main.py, según tu sistema operativo.

Selecciona una opción del menú e introduce los datos solicitados.

Para finalizar, selecciona la opción 7.

4. Ejemplos de uso

Registrar un comentario

Entrada:

Python es fácil de aprender.

Resultado:

Comentario registrado correctamente.

Buscar una palabra

Palabra buscada: C++

Resultado: el programa muestra los comentarios que contienen esa secuencia de caracteres. Si no encuentra coincidencias, informa al usuario.

Contar palabras

Comentario:

C++ es difícil de aprender.

Resultado: 5 palabras.

Mostrar un resumen

El programa presenta el comentario seleccionado, la cantidad de caracteres, el número de palabras y las apariciones de la palabra buscada.

5. Conceptos aplicados

Cadenas de texto: manipulación y análisis de información textual.

Listas: almacenamiento de los comentarios registrados.

Tuplas: agrupación de los resultados del análisis.

Funciones: organización y reutilización del código.

Ciclos y condicionales: recorrido de comentarios y control del menú.

Métodos de cadenas: uso de strip(), lower(), upper(), split() y count().

Manejo de errores: validación de entradas y control de opciones incorrectas.

6. Objetivo del proyecto

Practicar los fundamentos de programación en Python mediante el registro y análisis de comentarios, aplicando estructuras de datos, operaciones con cadenas y funciones propias.
