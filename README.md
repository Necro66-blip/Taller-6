Analizador de comentarios
Curso: Lógica de Programación I
Descripción del proyecto
Programa en Python que permite registrar y analizar comentarios. Sus funciones incluyen buscar palabras, contar palabras y apariciones, y generar resúmenes de los comentarios.
Requisitos generales
Tener Python 3 instalado.
Contar con el archivo main.py.
Disponer de una terminal o editor de código.
No requiere instalar librerías externas.
Instrucciones de ejecución
Guarda el código en un archivo llamado main.py.
Abre una terminal en la carpeta del proyecto.
Ejecuta el comando:
python main.py
Selecciona una opción del menú.
Para salir, selecciona la opción 7.
Ejemplos de uso
Registrar un comentario:
Entrada: Python es fácil de aprender.
Resultado: Comentario registrado correctamente.
Buscar una palabra:
Palabra: C++
Resultado: muestra los comentarios que contienen esa palabra.
Contar palabras:
Comentario: C++ es difícil de aprender.
Resultado: 5 palabras.
Mostrar resumen:
Presenta el comentario, la cantidad de caracteres, las palabras y las apariciones de la palabra buscada.
Conceptos aplicados
Cadenas de texto.
Listas y tuplas.
Funciones y ciclos.
Condicionales.
Métodos como strip(), lower(), split() y count().
Manejo de errores.
Objetivo:
Practicar los fundamentos de Python mediante el registro y análisis de comentarios.
